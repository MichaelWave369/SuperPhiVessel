# Asset Provenance

Super Φ.Vessel contains distinctive visual artwork and embedded runtime assets.

Before an asset is redistributed under the repository's MIT terms, its provenance and licensing status should be recorded here.

## Status labels

- **ORIGINAL** — created by the project author(s)
- **GENERATED** — generated specifically for this project with redistribution rights
- **THIRD_PARTY_LICENSED** — third-party asset with a compatible documented license
- **UNKNOWN / REVIEW** — provenance not yet established; do not assume MIT coverage

## Current policy

Until the current standalone runtime is added and its embedded assets are inventoried, embedded visual assets should be treated as **UNKNOWN / REVIEW** for licensing purposes unless their origin is independently documented.

The repository MIT license applies to source code and documentation except where a file or asset is explicitly marked otherwise.
