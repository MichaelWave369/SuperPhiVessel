# Super Φ.Vessel v2.0-alpha.11.0.54.10 — Service Models Handler Restoration

Status: **ALPHA prerelease**

This release promotes the exact standalone runtime already verified in the live Netlify production deployment.

## Trigger

Opening **Service → Models** could blank the main content layer because UI bindings survived after three handler implementations were dropped during later runtime merges.

Observed failure family:

- `exportKeyring`
- `autoAssignOllama`
- `applyOllamaStabilityPreset`

## Repair

- Restores the complete known-good handler set still referenced by Service / Models.
- Preserves the existing portable-keyring warning and import/export behavior.
- Preserves Ollama auto-assignment and stability-preset behavior from the last working implementation.
- Adds `tests/service-models-render.test.js` so CI fails if any restored handler disappears while its UI binding remains.
- Changes no model authority, execution authority, BrainC authority, memory authority, or external-effect policy.

## Blank-state inheritance

The public data epoch remains:

`PV-PUBLIC-BLANK-2026-09-29-V1`

This hotfix does **not** establish a new epoch and therefore does not intentionally wipe state created after .54.8.
