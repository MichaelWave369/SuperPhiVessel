# Super Φ.Vessel v2.0-alpha.11.0.54.8 — Blank-State Release Hardening

Status: **ALPHA prerelease**

This is the first formal GitHub release line for the normalized Super Φ.Vessel repository.

## What changed

- Introduces `PV-BLANK-STATE-0.1`.
- Establishes public data epoch `PV-PUBLIC-BLANK-2026-09-29-V1`.
- Clears legacy Vessie-owned browser persistence once before identity, session, conversation, memory, receipt, and WorkObject recovery.
- Preserves unrelated browser storage on the same origin.
- Rotates recovery writes to `parallax_vessel_recovery_public_epoch_1` and requests deletion of the legacy recovery database.
- Removes operator-specific seeded memory from the canonical public runtime.
- Preserves Vessie's ability to create and retain new state after the current epoch is established.
- Adds deterministic CI verification for the blank-state migration.
- Retains the Frozen Challenger Bench behavior and existing governance boundaries.
