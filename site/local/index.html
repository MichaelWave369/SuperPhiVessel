Download a portable Windows ZIP with its own Node.js runtime. Double-click a launcher to open a private browser dashboard that can show your actual locally installed Ollama models.

Download Local Console for Windows ↓ Open hosted Vessie ↗

Start in three steps

  1. Download the ZIP above and choose Extract All.
  2. Open the folder and read START_HERE.txt. No installer or administrator account is needed.
  3. Double-click Start-Local-Vessie.cmd, then press Discover my local models in the local browser.

The local console opens at http://127.0.0.1:8791/ and stops when you close its command window. Ollama must already be running on 127.0.0.1:11434 to show your models.

What stays protected

The server listens only on loopback, uses an ephemeral per-process read-only API secret, enforces an exact Host and same-origin policy, and has no model execution or memory/agent access endpoint.

This is a local model inventory console, not the full canonical SuperPhiVessel runtime. The hosted React website is separate and does not automatically gain access to this local dashboard. No model install, inference, paid calls, cloud upload, or routing approval occurs.

If Windows or your antivirus blocks a downloaded program, verify the origin and source. Do not disable device security to force it.
