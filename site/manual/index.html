MODELS & SERVICE

Choosing compute

Service → Models exposes provider configuration, Local Ollama discovery, the Brain Registry, AutoFabric, Model Scout, and Challenger tools. Discovery does not equal approval, and approval does not silently activate a model.

MEMORY

What remembering means

PV-MEM is Vessel-scoped context. Recall is not truth promotion, does not refresh expiry, and does not grant authority. Public builds use a blank-state epoch so prior operator state is not shipped as somebody else's starting memory.

WEB

Reading vs interacting

Direct Research handles ordinary read-only public web observation. Browsallax is the governed interactive lane for rendered-app inspection, forms, login/session state, downloads, and user-requested browser operation.

TROUBLESHOOTING

When something goes blank

Confirm the runtime version, hard-refresh once, then open DevTools → Console and capture the first red ReferenceError/TypeError. The independent boot contract can report failures even when the main runtime never finishes starting.
