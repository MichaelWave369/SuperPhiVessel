From nothing to a first look.

No Git clone. No Node.js setup. No TLS certificate required for this first step. Download a small ZIP, inspect it, then double-click the launcher. It checks for local Ollama read-only and opens Vessie's hosted React cockpit.

Download Windows Starter ZIP ↓ Open Vessie online ↗

Three steps

  1. Download the ZIP and Extract All in Windows.
  2. Read START_HERE.txt and review the launcher if you wish.
  3. Double-click Start-Vessie.cmd. No administrator access needed.

If Windows blocks the downloaded script under its execution policy, do not change security settings to force it. You can still use the online Vessie cockpit directly.

What this actually does

The starter checks 127.0.0.1:11434/api/tags for a local Ollama inventory, displays model names in your own terminal if available, and opens Vessie's public React page.

It does not install the full SuperPhiVessel runtime or make the website run your local models. Secure browser-to-local model discovery is a separate R2 field pilot that needs your later approval and trusted TLS setup. It never sends your local model list or credentials to the website, starts an internet-facing server, or grants execution authority.
