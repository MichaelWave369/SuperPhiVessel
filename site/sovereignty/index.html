BOUNDARIES BEFORE CONVENIENCE

      
What this does not do.

      

        
No automatic memory extraction
It does not discover Vessie's localStorage, IndexedDB, PV-MEM database or browser sessions. A source file must come from an operator-controlled export.

        
No identity or permission import
Record text cannot restore an identity, authorize execution, load a model, or grant access to another service.

        
No confidentiality guarantee after download
JSONL is plaintext, not encrypted. Store it on a protected device and review mapped text before sharing it.
